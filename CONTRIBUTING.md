# Guía de Contribución - App Loops

## Bienvenido

Gracias por contribuir a App Loops. Aquí encontrarás las directrices para contribuir al proyecto.

## Cómo Contribuir

### 1. Reportar Bugs
- Abre un issue en GitHub
- Describe el bug con detalle
- Incluye pasos para reproducir
- Agrega screenshots si es necesario

### 2. Sugerir Mejoras
- Abre un issue con el tag "mejora"
- Describe la mejora propuesta
- Explica por qué sería útil

### 3. Enviar Cambios
1. Haz fork del repositorio
2. Crea una rama para tu feature
3. Haz tus cambios
4. Envía un pull request

## Convenciones de Código

### Commits
- Usa mensajes de commit claros
- Formato: `<tipo>: <descripción>`
- Tipos: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

### Archivos
- Usa JSON para datos estructurados
- Mantén la consistencia en el formato
- Documenta cambios importantes

## Estructura de Archivos

### Para Tareas
- Ubicación: `tasks/`
- Formato: `task-XXX.json`
- Usa la plantilla en `templates/task-template.json`

### Para Proyectos
- Ubicación: `projects/`
- Formato: `project-XXX.json`
- Usa la plantilla en `templates/project-template.json`

## Revisión de Código

- Todos los pull requests requieren revisión
- Mantén los cambios pequeños y enfocados
- Incluye documentación cuando sea necesario

## Preguntas

Si tienes preguntas, abre un issue con la etiqueta "pregunta".
