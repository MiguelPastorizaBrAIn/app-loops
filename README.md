# App Loops - Gestión de Proyectos y Tareas

## Descripción
Repositorio para la configuración y gestión del sistema de Loops con tareas y proyectos.

## Estructura del Proyecto
- `config/` - Configuración del sistema
- `tasks/` - Tareas individuales
- `projects/` - Proyectos completos
- `loops/` - Definición de Loops

## Configuración
Este repositorio contiene la configuración para el sistema de Loops que incluye:
- Gestión de tareas
- Gestión de proyectos
- Flujo de trabajo basado en Loops
